# thimble

This is a sewing notion. It is also a Windows program that thinks it is 1999 and that your phone line is a personality trait.

## What it does

You double-click it. A real window appears. Not a browser. The browser was invited and did not RSVP.

Then the running man runs, the modem makes beep noises with the dignity of a fax machine at a wedding, and the software announces that you have mail. You do have mail. It is from 1999. It is not urgent. It has never been urgent.

After that you may:

- Read mail from people who are not real
- Enter a chat room where SoccerMom22 is always about to go to dinner
- Type a keyword like you are casting a spell
- Watch a stock quote that still uses fractions, because decimals had not yet won
- Sign off and be told goodbye, which is more closure than most apps offer

## How to start

Double-click `Launch America Online.bat`.

If the bat file is shy, double-click `AmericaOnline.exe` directly. It is a Win32 window. It has a menu bar. It has buttons. It has opinions about your screen name.

Screen names are 3 to 16 characters and may not contain a space. `SteveCaseFan` is fine. `Steve Case Fan` is a crime.

Any password works. The password is not saved, not sent, and not judged. `password` is traditional. `hunter2` is a lifestyle.

## Locations

- Home. The kitchen phone. Someone will pick up.
- Office. Dial 9. Feel important.
- Hotel. The bedside phone. The cord is short on purpose.
- Busy exchange. The line is busy. This is the most historically accurate button in the program.

Turn the modem speaker on if you want the neighbors to know you are online. Turn it off if you have grown as a person.

## Keywords

`mail` `chat` `news` `sports` `games` `weather` `stocks` `kids` `finance` `pictures` `help` `internet` `buddy`

If you type a keyword the program does not know, it will tell you, gently, that you are lost. This is also historically accurate.

## What it does not do

It does not dial a modem.
It does not call AOL.
It does not charge you $2.95 an hour, even though it thinks about it.
It does not install a toolbar.
It does not mail you a CD.
It does not know your password, and it does not want to. Please do not tell it.

## Self-test

`AmericaOnline.exe selftest`

It writes `AmericaOnline-selftest.txt` and feels very good about itself.

## Legal-ish

This is a recreation, not America Online. The running man is a guest. If the real running man shows up, offer him a chair and a phone line.
