America Online 5.0 — native Windows window
==========================================

This is a Win32 program. It opens its own overlapped window with a
menu bar, edit boxes, buttons, and list boxes. It is not a browser
page and it does not use mshta.

START
-----
Double-click "Launch America Online.bat"
or double-click AmericaOnline.exe

SIGN ON
-------
Screen name: 3 to 16 characters, no spaces. Any password.
Home / Office / Hotel dial a simulated 555 number.
Busy exchange plays a busy signal and returns to Sign On.
Modem speaker uses the Windows Beep driver for the handshake tones.

AFTER YOU ARE ON
----------------
Go To: Welcome, Channels, News, Sports, Games, Weather, Quotes,
Kids Only, Pictures, Internet, People Connection.
Mail: Read, Write, Delete. A reply is dropped in the mailbox.
Keyword box, top right: mail, chat, news, sports, games, weather,
stocks, kids, finance, pictures, help, internet, buddy.
Sign Off shows Goodbye, then the sign-on window again.

Nothing is dialed. Nothing is sent to AOL.

Self-test: AmericaOnline.exe selftest
It writes AmericaOnline-selftest.txt beside the program.
